# Security Policy

## Supported Versions

Only the `main` branch / latest release is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability in **Google Codmod Web Wrapper**, please **do not** open a public GitHub issue.

1. Send an email to the repository maintainer with:
   - A description of the vulnerability and its impact.
   - Steps to reproduce or a simple Proof-of-Concept (PoC).
   - Any suggested remediations.
2. You will receive an initial response within 48 hours acknowledging receipt of your report.
3. Once the vulnerability is verified, we will issue a security patch and credit your disclosure in the release notes.
