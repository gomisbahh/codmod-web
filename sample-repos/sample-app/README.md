# Sample Application for Local Assessment

This is a sample repository folder (`/repos/sample-app`) provided for local testing with the Codmod Web Wrapper.

## Overview
- This folder demonstrates how local repositories on your Mac/host machine can be mounted into Docker Compose (`/repos`) and processed directly.
- Select `/repos/sample-app` in the Web GUI using the **📁 Browse Folder...** dialog to run an assessment on this codebase.
